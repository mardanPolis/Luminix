# SURVIVAL GAME

**Core Idea:**
A colony simulator set in a post-apocalyptic AI world, where you control a lost character trying to survive. Build, fight, hide, and help others to survive.

## Technical
### Project layout
- `SurvivalGame/` — main game code (entities, rendering, mod handling).
- `docs/` — project documentation.

### Recommendations
- IDE - `Visual Studio Code`

### Requirements
- `.NET 10.0 SDK and RUNTIME`

### How To Run
Build:
```bash
dotnet build SurvivalGame.sln -c Debug
```
Run *(from project folder):*
```bash
dotnet run --project SurvivalGame/SurvivalGame.csproj -c Debug
```
